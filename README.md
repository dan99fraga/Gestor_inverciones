# Gestor_inverciones
Aplicación personal para gestionar cartera de inversiones. El proyecto esta en fase de definición funcional: primero iré organizando las funciones y decisiones; el desarrollo del código será posterior a esto.

# Objetivo
El objetivo es llevar un registro de tus inversiones y movimientos del capital de varios bróker unificados en una sola app para mas control y seguimiento de estas, tanto con una visión de las cuentas juntas como de cada cuenta independientemente.

# Funcionalidades previstas para una primera versión
- Gestionar acciones, ETF, bonos, efectivo y otros activos.
- Registrar cada operación individual realizada manualmente.
- Introducir los precios de compra de los activos manualmente.
- Calcular el precio de venta usando el método de precio medio ponderado.
- Mantener el efectivo separado por divisas y por cuentas o bróker y con una alternativa a ver todo tu efectivo global.
- Registrar cada cambio realizado en las carteras de manera manual y guardando la fecha en la que se realiza cada operación.
- Registrar los dividendos obtenidos con importe bruto, retenciones, gastos e importe neto, también se tendrá en cuenta los dividendos futuros de cada activo que tengamos en nuestra cartera. Y con una función en particular de poder ver la cantidad de dividendos a obtener en cada mes del año, así como su total anual.
- Corregir operaciones mediante edición o anulación, conservando la trazabilidad.
